# Overview

In this project I was attempting to take my experience and enthusiasm of the Roman literature and apply it a project of analysis using the R programming language. I have not touched it up to this point so it was an incredible opporunity to explore the capabilities of this phenomenal language!

This project takes a JSON file which contains a full list of Roman authors and their prospective works from the earliest periods of Roman history and analyzes the literary production before and after the fall of the Roman Republic in 44 BC.

I wrote this software because I was interested in understanding the cultural developments which stem from Rome's culture. My hypothesis was that following the fall of the Roman Republic, there would be a noticeable increase in literary production due to the fact the empire funded the development of artists. This appeared to be markedly true. However, it is important to recognize that it is very possible that much literature from the early and late republic failed to survive and as such we have incorrect conclusions and data.

# Development Environment

I used RStudio as my primary development environment for writing and executing the R code. RStudio provides a comprehensive array of tools to manage scripts, create visualizations of data, and manage the data accordingly.
 
The primary libraries used include `jsonlite` for reading and parsing JSON data, and `ggplot2` for creating the visualizations of literary and cultural production before and after the fall of the Roman Republic.
